# Cadence Rituals
last-updated: YYYY-MM-DD

## Weekly ritual (every Monday, ~30 min)

**Purpose:** Keep momentum, surface blockers, update memory.

**Steps:**
1. Open Claude Code, cwd = `~/claude-business`
2. Review `deliverables/` for anything approved last week — is it live? If not, why?
3. Check active projects in `projects/` — any blockers?
4. Optional: run E24 Analytics Reporter prompt for the week's metrics
5. Update hub/07/operating-rules.md decision log if any decision was made last week
6. Note one thing to test or ship this week in a scratch note or task tool

**Duration target:** 30 minutes max. If it takes longer, reduce scope.

---

## Monthly ritual (first Monday of month, ~60 min)

**Purpose:** Health check, hub maintenance, big picture.

**Steps:**
1. Run `/business-hub-audit` — get the score and top 3 gaps
2. Fix tier-1 gaps or schedule them for this week
3. Update hub/05/marketing-growth-stack.md with the previous month's:
   - Ad account changes
   - Email list size
   - Creative library additions (add winning ads)
4. Review hub/01/icp-personas.md — any new insight from customer calls or support?
5. Review competitor notes (hub/05/marketing-growth-stack.md — competitor tracking)
6. Check hub section last-updated dates — flag any section >60 days old

**Duration target:** 60 minutes. Calendar block it.

---

## Quarterly ritual (start of each quarter, ~2 hours)

**Purpose:** Strategic review, offer and positioning refresh.

**Steps:**
1. Run `/pricing-positioning-memo` with trigger "quarterly review"
2. Review offer ladder — any offer to retire, add, or reframe?
3. Review hub/08/human-roles.md — any roles to hire or restructure?
4. Review integrations matrix — any C2 connections to activate?
5. Review hub/07/operating-rules.md — any rules to update?
6. Set 3 quarterly goals and add to operating rules decision log

**Duration target:** 2 hours split across 2 sessions.

---

## After each major campaign (within 48 hours of end)

**Steps:**
1. Run E24 Analytics Reporter for campaign summary
2. Update hub/05/marketing-growth-stack.md creative library:
   - Add winners with notes on what worked
   - Add losers with notes on what didn't
3. Update hub/03/analytics-plan.md funnel benchmarks with actuals
4. If offer or pricing changed: update hub/01/offer-ladder.md and hub/03/product-catalog.md

---

## After a major business decision (within 24 hours)

**Steps:**
1. Add a dated entry to hub/07/operating-rules.md decision log
2. Update any hub files directly affected by the decision
3. If the decision changes an offer, price, or guarantee: run `/business-hub-audit` section:01 to verify consistency
